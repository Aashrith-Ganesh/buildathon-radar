BUILDATHON RADAR - SCRIPT PROPERTIES & GITHUB SECRETS CHEAT SHEET
================================================================================

--------------------------------------------------------------------------------
PART 1: GOOGLE APPS SCRIPT - SCRIPT PROPERTIES
--------------------------------------------------------------------------------
Where to add:
  1. Open your project at https://script.google.com/
  2. Click Project Settings (Gear icon ⚙️ on the left panel)
  3. Scroll to "Script Properties"
  4. Click "Add script property"

Properties to add:

KEY:   WEBHOOK_SECRET
VALUE: whsec_b3a8e99d14f72c01e56b82390a4dfb7c
(Note: You can use this pre-generated token or generate your own secure string)

KEY:   RECIPIENT_EMAIL
VALUE: [YOUR_GMAIL_ADDRESS]@gmail.com
(Optional: If omitted, Google Apps Script defaults to your logged-in Google Account)

KEY:   SENDER_NAME
VALUE: Buildathon Radar

KEY:   DUPLICATE_PREVENTION_ENABLED
VALUE: true

--------------------------------------------------------------------------------
PART 2: GOOGLE APPS SCRIPT - DEPLOYMENT STEPS
--------------------------------------------------------------------------------
1. In the top right of the Google Apps Script editor, click:
   Deploy > New deployment
2. Select type: Web app (Gear icon ⚙️)
3. Configuration:
   - Description: Buildathon Radar Webhook v1
   - Execute as: Me (your_email@gmail.com)
   - Who has access: Anyone
4. Click "Deploy" and authorize permissions if prompted.
5. Copy the Web app URL (ends with /exec):
   Example: https://script.google.com/macros/s/AKfycbx.../exec

--------------------------------------------------------------------------------
PART 3: GITHUB REPOSITORY - SECRETS
--------------------------------------------------------------------------------
Where to add:
  1. Open your repository on GitHub
  2. Navigate to: Settings > Secrets and variables > Actions
  3. Click "New repository secret"

Secrets to add:

NAME:  GAS_WEB_APP_URL
VALUE: https://script.google.com/macros/s/[YOUR_DEPLOYMENT_ID]/exec
(Paste the Web App URL copied from Step 2 above)

NAME:  GAS_WEBHOOK_SECRET
VALUE: whsec_b3a8e99d14f72c01e56b82390a4dfb7c
(Must match the exact WEBHOOK_SECRET added to Google Apps Script above)

NAME:  RECIPIENT_EMAIL
VALUE: [YOUR_GMAIL_ADDRESS]@gmail.com
(Optional: overrides target email)

--------------------------------------------------------------------------------
PART 4: VERIFYING IN GITHUB ACTIONS (DRY-RUN)
--------------------------------------------------------------------------------
Once secrets are saved:
  1. Go to repository "Actions" tab on GitHub
  2. Click "Weekly Buildathon Digest" workflow on the left
  3. Click "Run workflow" dropdown on the right
  4. Select:
     - dry_run: true
     - mock_submission: true
  5. Click "Run workflow" to verify complete green execution!
